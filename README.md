# 📇 Meu Cartão Profissional Digital

Este repositório armazena o projeto prático de um cartão profissional digital, desenvolvido como parte do meu portfólio acadêmico para o curso de Ciência da Computação.

## 🎯 Objetivo do Projeto
O objetivo principal deste projeto foi aplicar, na prática, os fundamentos iniciais de desenvolvimento web, consolidando o aprendizado sobre estruturação de páginas e estilização customizada por meio de arquivos externos.

## 💻 O que a página apresenta
A página consiste em um cartão de visitas digital responsivo e moderno, apresentando:
- **Perfil Profissional:** Nome, cargo/área de atuação e uma breve descrição acadêmica e profissional.
- **Identidade Visual Customizada:** Design limpo em modo escuro (*Dark Mode*), otimizado para leitura.
- **Links de Contato:** Botões interativos que direcionam o visitante para redes profissionais e portfólios.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Utilizado para a marcação estrutural e semântica de todos os elementos textuais e links.
- **CSS3:** Utilizado para a estilização do layout, definição de cores, espaçamentos, efeitos de transição nos botões (*hover*) e responsividade.
